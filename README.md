# Система управления расписанием, оценками и посещаемостью

## Описание проекта

Данное мобильное приложение разработано на Flutter с использованием Firebase в качестве backend-сервиса.

Система предназначена для автоматизации учебного процесса: отображение расписания занятий, учет посещаемости студентов и фиксация оценок. Приложение поддерживает несколько ролей пользователей: студент, преподаватель и администратор.

---

## Цель проекта

Создание удобного и простого в использовании цифрового инструмента для просмотра и управления учебным расписанием, а также учета успеваемости студентов.

---

## Роли пользователей

### Студент:
- Просмотр расписания занятий
- Просмотр оценок
- Просмотр посещаемости
- Просмотр информации о преподавателях и предметах

### Преподаватель:
- Просмотр своих занятий
- Отметка посещаемости студентов
- Выставление оценок 

### Администратор:
- Создание и редактирование расписания
- Добавление новых занятий
- Добавление преподователей
- Добовление студентов и создание групп
- Управление данными в системе

---

## Основной функционал

- Авторизация пользователей (Firebase Authentication)
- Разделение по ролям
- Расписание по дням недели
- Привязка занятий к группам
- Система посещаемости
- Система оценок
- Добавление преподователей и студентов
- Хранение данных в Cloud Firestore

---

##  Структура данных Firestore

### schedule
- day — день недели
- group — группа
- subject — предмет
- teacher — преподаватель
- time — время занятия
- lesson — номер пары

### users
- name — имя пользователя
- role — роль (student/teacher/admin)
- group — группа (для студентов)
- email - почта пользователя

### attendance
- studentId
- lessonId
- status (присутствовал / отсутствовал)

### grades
- text

### groups
- name

## subjects
- name
